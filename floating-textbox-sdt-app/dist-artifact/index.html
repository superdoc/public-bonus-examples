How it works
  • The button finds the page under the middle of the editor viewport, then the first body paragraph painted on that page, and anchors the text box to it.
  • The text box is written into the DOCX (export → patch document.xml → replaceFile): wp:wrapNone, page-relative position, a:noFill, zero insets, one paragraph with an inline plain-text w:sdt.
  • The SDT value is changed live through activeEditor.doc.contentControls.text.setValue.
  • Position and size changes rewrite the anchor geometry and reload the document. The SDT is the only content of the box with zero insets, and the app adds CSS so its rendered chrome fills the whole text box.
